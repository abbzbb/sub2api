# Issue #603 latency observability and scheduling coverage

This is a six-item implementation matrix tied to the production paths found on
the `origin/production` baseline `77455cf755fa0f119367b911704f11df88e7917e`.
The measurements in the issue are one operator's single-instance observations;
they motivate instrumentation, but do not establish universal causes or tune
defaults automatically. In particular, post-upload wait is not a measurement of
prefill or pure model time.
